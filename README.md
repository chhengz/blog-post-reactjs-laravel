# Full-Stack Development (Blog post) - Reactjs + Laravel

This Project develop with ReactJS and Laravel.

## ✨Features

- Full authentication with user
- User can post and edit only their own posts
- Working with jwt token for security protections

---

## 👤 Client

use `npm install` to install node packages \
use `npm run dev` to start development client \
use `npm run build` and `npm run preview` to build and peview for production

---

## 🚪 Server

use `composer install` to install vender packages \
use `php artisan key:generate` to generate new key for laravel app \
use `php artisan migrate` to migrate the database with sqlite or (you can setting up your own database configuration) on `.env` \
use `php artisan serve` to start the server \
use `php artisan route:list` to lists all routes both view route and api route

---

## 🐋 Docker Setup

use `docker compose up -d --build` to build docker image
